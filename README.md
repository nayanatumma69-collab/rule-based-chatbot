# 🤖 Rule-Based Chatbot

A simple rule-based conversational chatbot built using Python, Regular Expressions (Regex), and pattern matching.

## 📌 Project Overview

This chatbot identifies the user's intent by matching their input against predefined patterns and provides an appropriate response.

The chatbot supports conversations related to greetings, AI internship information, technical support, chatbot capabilities, and farewell messages.

## 🎯 Objective

The objective of this project is to understand the basic concepts of conversational AI, intent recognition, text preprocessing, and rule-based NLP.

## 🛠️ Technologies Used

- Python
- Regular Expressions (Regex)
- Random module
- Rule-Based NLP
- Google Colab

## ✨ Key Features

- Regex-based intent recognition
- Text preprocessing
- Multiple conversation topics
- Randomized responses
- Fallback responses
- Interactive conversation
- Exit/quit/bye handling

## 🧠 How It Works

1. User enters a message.
2. The chatbot cleans and processes the input.
3. Regex patterns are used to identify the user's intent.
4. A suitable response is selected.
5. The chatbot returns the response.
6. If no matching intent is found, a fallback response is provided.
